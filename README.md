## You need:
* **Python**: 3.10+ (or latest version)
* **Git**
* **Pip**: package manager

## Installation & config.
### 1. Clone repo

### 2. Create virtual environment (`venv`)
```bash
python -m venv venv
```

### 3. Activate virtual environment

* **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
* **Linux / macOS / Git Bash:**
  ```bash
  source venv/bin/activate
  ```

### 4. Update package manager and install dependencies
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```
